# Step 2: jQuery Selectors Inspector

Open `index.html` with VS Code Live Server or in your browser.

### What this example demonstrates
1. **ID Selector (`#heading`)**: Changes the heading's color to navy.
2. **Class Selector (`.student`)**: Targets elements sharing the `.student` class.
3. **Element/Tag Selector (`p`)**: Targets all `<p>` elements on the page.
4. **Interactive Highlighters**: Click the highlight buttons to visually inspect which elements match each selector.
5. **Dynamic DOM Insertion**: Type a name and add a new student card, then re-run the counter to see the count update live.
