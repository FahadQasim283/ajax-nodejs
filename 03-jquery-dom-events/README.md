# Step 3: DOM Manipulation and Events Studio

Open `index.html` with VS Code Live Server or in your browser.

### What this example demonstrates
1. **Reading Form Values**: Uses `$("#name").val()` to retrieve user input.
2. **Dynamic HTML Updates**: Uses `$("#message").text()` for validation errors and `$("#message").html()` for rich greeting cards.
3. **Keyboard Events**: Listens to `keydown` so pressing `Enter` submits the form.
4. **Input Events**: Listens to `input` for real-time character counting and typing state tracking.
5. **Interactive UI Effects**: Includes form validation shake animation, avatar generation, and quick-fill test chips.
