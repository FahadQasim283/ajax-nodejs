# jQuery, AJAX, Node.js and Express Lab

This workspace contains one isolated example per learning step. Open a single
step folder, follow its `README.md`, and run only that example. The examples
build gradually from browser-side jQuery to frontend/backend communication.

## Learning path

| Step | Folder | What students learn |
| --- | --- | --- |
| 01 | `01-jquery-introduction` | Load jQuery and select an element |
| 02 | `02-jquery-selectors` | ID, class, and element selectors |
| 03 | `03-jquery-dom-events` | Read values, update HTML, and handle clicks |
| 04 | `04-json-basics` | Read JavaScript objects and arrays |
| 05 | `05-ajax-public-api` | Send a GET request and display JSON |
| 06 | `06-node-http-server` | Create a server with Node.js only |
| 07 | `07-express-get-api` | Create an Express GET endpoint |
| 08 | `08-express-post-api` | Receive JSON with a POST endpoint |
| 09 | `09-cors-student-app` | Connect jQuery to Express with GET and POST |

## Requirements

- Node.js 18 or newer for steps 06–09
- A browser
- VS Code Live Server (recommended for frontend steps)

Do not open the entire workspace as one application. Work inside one numbered
folder at a time. Backend folders contain their own `package.json`, so
dependencies and commands remain isolated.
