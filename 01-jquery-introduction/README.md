# Step 1: jQuery Introduction & Event Playground

Open `index.html` with VS Code Live Server or directly in your browser.

### What this example demonstrates
1. **Core jQuery Selection**: Selects `#heading` with `$("#heading")` and updates its text using `.text()`.
2. **Input & Keyboard Events**: Type in the text box to watch the heading update live via `input` and `keyup` events.
3. **Mouse Events**: Hover over or click the heading box to trigger `mouseenter`, `mouseleave`, and `click` effects.
4. **jQuery Animations**: Click the effect buttons to test `.fadeToggle()` and `.slideToggle()`.
5. **Live Activity Console**: Inspect on-page logged events alongside the browser DevTools console (`F12`).
